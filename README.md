# Python To-Do List

A simple command-line To-Do List application built using Python.

## Features
- Add new tasks
- View saved tasks
- Delete tasks
- Store tasks in a text file using file handling

## Technologies Used
- Python
- File handling

## How to Run
1. Make sure Python is installed.
2. Clone or download this repository.
3. Run the Python file:

```bash
python3 main.py
```
